# Fonts

- **TeX Gyre Adventor** (`texgyreadventor-*.otf`): the labelmaker wordmark. A free revival of
  Avant Garde Gothic by GUST, from CTAN (`fonts/tex-gyre/opentype`). Licensed under the GUST Font
  License (`GUST-FONT-LICENSE.txt`), which allows use and redistribution, including on the web.
  Used unmodified.
- **Instrument Sans**: everything else. Loaded through `next/font/google` (SIL Open Font License),
  self-hosted with the app at build time.
